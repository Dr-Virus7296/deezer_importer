# Deezer Importer: запуск на Windows и получение ARL

## Часть 1. Запуск на Windows

1. **Скачайте и установите Python 3.10 или новее.**
   Ссылка: https://www.python.org/downloads/windows/
   (или сразу страница с последней версией: https://www.python.org/downloads/)
   В первом окне установщика обязательно отметьте галочку **«Add python.exe to PATH»**.
2. **Распакуйте архив** в обычную папку, например `C:\deezer_importer`. Не запускайте скрипт из-под архива.
3. **Откройте командную строку в этой папке.** Зайдите в папку в проводнике, нажмите на адресную строку, напишите `cmd` и нажмите Enter.
4. **Поставьте библиотеки:**
   ```
   pip install requests curl_cffi yandex-music zvuk-music
   ```
   - `requests` нужен всегда.
   - `curl_cffi` желателен, но необязателен: без него используется обычный `requests`.
   - `yandex-music` нужен для Яндекс.Музыки, `zvuk-music` для Zvuk. Если пакет не находится, поставьте только те, что нужны.
   - Spotify и Apple Music работают на `requests`.
5. **Запустите:**
   ```
   python run.py
   ```
   Запускать нужно из папки со скриптом: `config.cfg` читается по относительному пути.
6. В меню выберите площадку (Яндекс, ВК, Zvuk, Spotify, Apple Music, свой список) или пункт 7 «Настройки Deezer».

### Что нужно в `config.cfg`

В архиве там заглушки (`...BlaBlaBla`). Нужны ваши значения, каждое в одной строке, без кавычек и пробелов:

```
ARL=ваш_arl
ACCESS_TOKEN=ваш_токен
```

- **ARL** нужен для поиска треков на Deezer. Как его достать, описано ниже.
- **ACCESS_TOKEN** нужен для создания плейлистов и добавления треков. Проще всего получить его в самом скрипте: пункт 7 «Настройки Deezer», затем «Автологин по email + пароль». Это не сработает, если вход в Deezer идёт через Google, Facebook или Apple.
- `COOKIES` можно оставить пустым: они нужны только для запасного HTML-поиска.

Если автологин вернёт и ARL, скрипт запишет его сам, и вручную доставать не придётся.

## Часть 2. Как достать ARL вручную

ARL — это cookie, по которой Deezer узнаёт ваш аккаунт. Это фактически пароль: никому его не показывайте и не выкладывайте `config.cfg` публично.

### Chrome, Edge, Brave, Opera

1. Откройте https://www.deezer.com и войдите в аккаунт.
2. Нажмите **F12**, вкладка **Application** («Приложение»). Если её не видно, нажмите `»` справа от вкладок.
3. Слева откройте **Storage → Cookies → https://www.deezer.com**.
4. Найдите строку **`arl`**.
5. Дважды щёлкните по значению в колонке **Value**, выделите всё (Ctrl+A) и скопируйте (Ctrl+C).

### Firefox

1. Войдите на deezer.com, нажмите **F12**, вкладка **Storage** («Хранилище»).
2. Откройте **Cookies → https://www.deezer.com**, найдите `arl` и скопируйте значение.

### Через расширение

Поставьте «Cookie-Editor», откройте его на странице deezer.com, найдите `arl` и скопируйте значение.

Вставьте ARL в `config.cfg` после `ARL=` либо через меню скрипта: пункт 7, затем «Вставить ARL вручную». В нормальном ARL обычно около 192 символов, без пробелов и кавычек.

### Важно

- **Не нажимайте «Выйти» на Deezer после копирования.** Выход аннулирует ARL. Лучше войти в приватном окне, скопировать ARL и просто закрыть окно.
- ARL может протухнуть при смене пароля или входе с других устройств. Если поиск перестал работать, достаньте его заново.
- Через `document.cookie` в консоли ARL не виден: cookie защищена HttpOnly. Используйте вкладку Application или Storage.
